# 食堂点餐小程序（food-order）

这是一个基于 uni-app 的家庭点餐演示项目，适合用于微信小程序、支付宝小程序、头条小程序、原生 App 等多端发布。

## 项目简介

本项目实现了一个家庭专用的点餐系统，包含以下核心功能：

- 登录页（管理员密码登录 / 游客访问）
- 菜品浏览与分类筛选
- 购物车管理与订单生成
- 管理员模块：上架菜品、下架/恢复菜品
- 个人主页：订单历史、用户信息展示
- 本地存储支持：菜品、购物车、订单历史、用户信息均保存在本地存储中

## 主要页面

- `pages/login/login`：登录页，支持管理员登录与游客进入
- `pages/index/index`：菜品展示页，支持按分类筛选与加入购物车
- `pages/cart/cart`：购物车页，支持移除商品、清空购物车、生成订单
- `pages/profile/profile`：个人主页，展示历史订单与用户信息
- `pages/admin/admin`：管理员模块，支持菜品管理

## 目录结构

- `common/food-data.js`：菜品数据与本地存储读写逻辑
- `pages/`：各个页面组件
- `static/`：演示图片和静态资源
- `uniCloud-aliyun/`：uniCloud 相关目录，包含云函数和数据库 schema 骨架
- `manifest.json`：uni-app 项目配置
- `pages.json`：页面路由与全局样式配置

## 运行方式

推荐使用 HBuilderX 打开项目：

1. 下载并安装 HBuilderX。
2. 在 HBuilderX 中打开 `food-order` 项目目录。
3. 选择运行平台：微信小程序、支付宝小程序、App 等。
4. 点击“运行”或“发行”进行预览和打包。

如果你希望使用命令行构建，请确认已安装 uni-app CLI 和相关依赖；本仓库当前没有顶层 `package.json`，所以更适合直接在 HBuilderX 中打开。
